## 1. How to read the tables

- **Routine** is a pseudocode routine of D3 (PS-01 to PS-19).
- **Planned Rust item** is `module::item`, where `module` is a path under `src/` of the existing crate (for example `numerical::grid`). The proposed layout is D3 Section 1.3.
- **Test** names the planned test and the independent reference it uses. Two kinds of location appear:
  - unit tests inside the module, written `module::tests::name`;
  - integration tests `btcs_verification::name` in `tests/btcs_verification.rs`, the driver `examples/verify_btcs.rs` (planned marker line `BTCS_VERIFICATION PASS`), regression tests `btcs_regression::name` in `tests/btcs_regression.rs`, and wrapper parity tests in `crates/strato-wasm/tests/parity.rs`.
- **References that do not depend on the BTCS code.** A test is only as strong as its reference. The references named are: (a) values evaluated by hand or by exact rational arithmetic *inside the test* from the formula of D2, for a small grid with one interval per material and for a grid with several; (b) a dense Gaussian elimination written in the test module (no new dependency); (c) the independent Sturm-Liouville solver `analytical::sturm_liouville::ModalRelease` (retained, no BTCS code); (d) the closed form of the homogeneous sphere (a series in `examples/verify.rs` today); (e) the single-mode exact solution $C(r,t) = \exp\left(-\pi^2 D t/\left(R\right)^2\right)\sin\left(\pi r/R\right)/\left(\pi r/R\right)$ for one material, derived in the verification plan; (f) the value of the release fraction of the synthetic case from a separate-language script that the repository already pins. (g) The diffusivity jump across a layer interface is NOT exercised by the property tests P8a, P11, P12, P15 and P16, which use equal diffusivities in the five layers. It is exercised, with five different diffusivities, by `btcs_verification::five_layer_release_vs_sturm_liouville_and_spatial_order` (release fraction against the Sturm-Liouville series) and `btcs_verification::interfaces_concentration_and_flux_continuity` (continuity of concentration and flux at the interfaces), and by the independent check of the regression suite, which asserts that the observed orders round to 1 in time and 2 in space (coordinator decision 49). A test that compares the solver with its own earlier output is a regression test and is labelled so; it is not evidence of correctness.
- **No tolerance is fixed in this document.** Each tolerance is set by the author of the test, before the first run, from an operation count or rounding analysis (floating-point checks) or from the observed refinement sequence (discretisation checks), and recorded with the reason. A failing test is reported and stays failing; no tolerance is relaxed to make a test pass (directive Section 11).
- **Numerical verification is not experimental validation.** None of these tests compares with a measurement.

## 5. Gaps and notes

1. **Independent references that do not yet exist.** The Sturm-Liouville module returns the release fraction only. The profile-level tests (centre value in (F12), single-mode checks in (F26), P8a, P11, P13) use the closed forms (d) and (e), which are implemented inside the tests. A profile function for the layered series, if wanted, is new work in `analytical` and needs its own review; this table does not assume it.
2. **Phase G.** The generation, decay and temperature equations are (F32) to (F46) of D2 Section 11; Section 2a and Section 3a above hold their rows. Not done: (F44) as a separate function and (F45) (the a-priori bound), the second-order behaviour of P22a on unequal spacings, and every mechanism of directive Section 17 beyond G1 to G4 (no trapping, grain-boundary transport, palladium or cracking).
3. **Property P14 and the order assertions.** The bands of plus or minus 0.2 of verification-plan rule R3 were withdrawn (coordinator decision 7). The convergence tests assert that an observed order rounds to the integer order `p` of the quantity tested, `|o - p| < 1/2` plus the propagated rounding uncertainty of the order; no band is fixed. The independent check of the regression suite applies the same rule with `p = 1` in time and `p = 2` in space and without a rounding allowance (its observed orders deviate from the integer by at most 0.07).
4. **Cross-reference in D2.** The introduction of D2 Section 5 cites (F15) for the statement that $C_N^{j+1}$ is not an unknown. The condition is (F18). This matrix and D3 use (F18). The document D2 itself has not been changed.
5. **Nothing in this table is a result.** The "Implemented in" column and every statement of the form "the test passes" are absent on purpose.
